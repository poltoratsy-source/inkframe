# Inkframe

**Открытая студия рисованных мультфильмов, которые пишет и рисует Claude.**

Пишешь идею («мультфильм для школьников, как лидар видит мир, 60 с»), выбираешь стиль и настройки.
Claude пишет сценарий и раскадровку, рисует сцены кадр за кадром, и на экране видно, как ролик рождается:
сначала набросок карандашом, потом акварель. Любую сцену можно поправить одной фразой — Claude перерисует
только её. В конце — MP4 с озвучкой и музыкой.

[English version](README.md) · **Демо:** https://YOUR-GITHUB-NAME.github.io/inkframe/ *(появится после первого пуша, см. [Демо-сайт](#демо-сайт-github-pages))*

## Что готово: этап 2, настоящий движок

У Inkframe два движка за одним интерфейсом `StudioEngine` (`lib/engine/types.ts`):

| | Демо-движок (`INKFRAME_ENGINE=demo`, по умолчанию) | Настоящий движок (`INKFRAME_ENGINE=real`) |
|---|---|---|
| Раскадровка | проигрывает готовый мультфильм | пишет Claude (`claude -p` на этом компьютере); если Claude недоступен — раскадровка по шаблону |
| Рисование | заранее нарисованные кадры по таймеру | каждая сцена рисуется на p5.js + p5.brush в headless Chrome: набросок карандашом, потом цветной черновик, вживую |
| Голос | волна демо-мультфильма | edge-tts на каждую реплику; сцены растягиваются под голос |
| Правка сцены | CSS-эффект | Claude (или простые правила) меняет описание или слова сцены; перерисовывается и переозвучивается только она |
| MP4 | демо-мультфильм | 1280×720, рисованные 12 кадров/с, наплывы, голос поверх приглушённой музыки, вшитые субтитры |

Демо-сайт на GitHub Pages всегда работает на демо-движке.

![Настоящий движок рисует сцену 1](demo/05-real-drawing.jpg)

### Как рисует настоящий движок

Claude не пишет код рисования. Раскадровка заполняет для каждой сцены **SceneSpec** (`lib/real/scene-spec.ts`), а
художник рисует его по четырём шаблонам (`renderer/templates.js`) и 25 предметам (`renderer/props.js`):

- `host` — Клод говорит со зрителем, рядом появляется предмет;
- `object` — один крупный предмет, до двух подписей со стрелками;
- `compare` — две вещи рядом с подписями, Клод переводит взгляд с одной на другую;
- `card` — финальная карточка с кодовым словом.

Места действия: комната, небо, луг, закат, ночь, космос, море, доска. Всё, чего нет в списках, отбрасывается,
поэтому раскадровка не может сломать художника.

![Кадры готового мультфильма «Почему небо голубое», 16,6 с](demo/06-real-frames.jpg)

Без видеокарты полная акварельная заливка стоит 10–20 с на кадр, поэтому черновики и чистовик рисуются плоскими
размывками на той же бумаге (около 0,6 с на кадр в три потока). `INKFRAME_WATERCOLOR=1` возвращает полную акварель
в чистовике. Мультфильм на 15 с: около минуты на черновики и 3 минуты на MP4 на 4-ядерном сервере; правка
перерисовывает одну сцену меньше чем за минуту, а следующий MP4 заново рисует только её.

## Как запустить

Нужен Node.js 20.9 или новее.

```bash
npm i
npm run dev          # http://127.0.0.1:3700
```

Через Docker:

```bash
docker compose up --build    # http://127.0.0.1:3700
```

Настройки — в `.env.local` (скопируй `.env.example`): `INKFRAME_ENGINE` (`demo` или `real`) и
`INKFRAME_DEMO_SPEED` (2 — вдвое быстрее).

### Настоящий движок

Нужны на том же компьютере: Chrome или Chromium (находится сам, или `CHROME_PATH`), ffmpeg, Python 3 с
`pip install edge-tts` и Claude Code (`claude`) со входом, либо свой API-ключ (ниже).

```bash
INKFRAME_ENGINE=real npm run dev
```

Проекты (черновики, клипы сцен, MP4) лежат в `projects/`. Все настройки настоящего движка перечислены в
`.env.example`: ожидание Claude и модель, режим «только шаблоны», число художников (не больше 3), программный GL,
масштаб чистовика.

### Свой ключ Claude

Нажми на плашку **Claude** вверху и вставь свой API-ключ Anthropic (`sk-ant-…`). Он записывается только в
`.env.local` на твоём компьютере: этот файл в `.gitignore` и в git не попадает, а в браузер ключ обратно не
отдаётся. Без ключа настоящий движок использует вход Claude Code на этом же компьютере.

## Демо-режим

Демо-движок (`lib/engine/demo.ts`) проигрывает по таймеру те же события, что будет присылать настоящий:
раскадровку, шаги работы, кадры-наброски, цветные кадры, дорожки голоса и музыки, готовое видео. Кадры, их
карандашные двойники и волны звука нарезаны из мультфильма про лидар скриптом `scripts/prepare-demo-assets.sh`
в `public/demo/`.

пока запущен `npm run dev`).

### Демо-сайт (GitHub Pages)

`npm run build:demo` собирает кликабельное демо в обычные статичные файлы в `out/`. Сервера нет: демо-движок
работает прямо во вкладке браузера (проекты живут, пока вкладку не перезагрузили), студия открывается по адресу
`/studio/?id=…`.

```bash
npm run build:demo                                   # сайт в корне домена
NEXT_PUBLIC_BASE_PATH=/inkframe npm run build:demo   # сайт по адресу https://<ник>.github.io/inkframe/
NEXT_PUBLIC_BASE_PATH=/inkframe npm run preview:demo # проверить на http://127.0.0.1:3701/inkframe/
```

Сборка рассчитана на корень своего адреса, поэтому открывай её через веб-сервер, а не двойным щелчком по
`index.html`.

[`.github/workflows/pages.yml`](.github/workflows/pages.yml) при каждом пуше в `main` прогоняет тесты, собирает
демо и публикует его. Включается один раз: **Settings → Pages → Source: GitHub Actions**.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Студия на 127.0.0.1:3700 |
| `npm test` | Тесты движков, редьюсера, раскадровки, звука, субтитров и настроек (test runner Node, Chrome не нужен) |
| `npm run typecheck` | Проверка TypeScript |
| `npm run build:demo` | Статичный демо-сайт в `out/` (`--out=<папка>` — в другую папку) |
| `node scripts/check-static.mjs <адрес>` | Проверка демо-сайта в headless Chrome: старт → отрисовка → видео играет |
| `npm run demo:record` | Видео-прохождение и снимки в `demo/` |
| `node --import tsx scripts/paint-check.ts <out.jpg> [rs] [ширина] [sketch\|fast]` | Рисует примеры всех шаблонов на одном листе |

## Как устроено

Next.js (App Router), React, TypeScript, Tailwind CSS. Сервер шлёт события движка по SSE; браузер складывает их
тем же чистым редьюсером (`lib/engine/reducer.ts`), что проверяют тесты. Настоящий движок — `lib/engine/real.ts` и
`lib/real/` (раскадровка, Claude CLI, художник, звук, ffmpeg), рисованная сцена — `renderer/`.
